# MyBots Inc.

**Open, modular physical AI for robotics research.**
🌐 [mybotsinc.com](https://mybotsinc.com)

🚧 Something is taking shape.

Robots are complicated. We're working on making them modular, open, and built to evolve.
The robots are not ready yet. The ideas are.

## What we're building

- **[OpenRobotaxi](https://mybotsinc.com/openrobotaxi/)**: an open, full-size self-driving research vehicle.
- **MyBots Virtual Vehicle**: a simulator built on NVIDIA Isaac Sim and ROS 2, so labs can start developing before the vehicle arrives.
- **[Research notes](https://mybotsinc.com/research/)**: sensor simulation, motion prediction, scene understanding, and end-to-end driving.
